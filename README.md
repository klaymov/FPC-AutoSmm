## 📌 Что такое AutoSMM?

**AutoSMM** — это плагин для полной автоматизации выполнения заказов на накрутку (подписчики, лайки, просмотры, реакции, часы просмотров и др.) на бирже FunPay через бота FunPay Cardinal.

### 🔥 Как это работает:
1. **Автоматический захват заказа**: клиент оплачивает лот на FunPay, в описании которого указан ID услуги.
2. **Мгновенный запрос ссылки**: бот сам пишет покупателю в чат FunPay, вежливо приветствует его и просит прислать ссылку.
3. **Проверка и подтверждение**: бот проверяет ссылку и предлагает покупателю подтвердить запуск (`+`), отменить заказ (`-`) или отправить другую ссылку.
4. **Запуск через API**: после подтверждения заказ мгновенно уходит в работу через API SMM-сервиса без вашего участия.
5. **Безопасность**: внутренние технические ошибки, ключи API и балансы скрыты от покупателя — он видит только понятные подсказки на русском языке.
6. **Контроль и завершение**: чекер отслеживает статус заказа и после выполнения пишет покупателю с просьбой подтвердить заказ на FunPay и оставить отзыв ⭐.
7. **Управление в Telegram**: подробная панель `/autosmm`, расчет чистой прибыли с учетом комиссии FunPay и быстрый просмотр очередей.

## ⚙️ Установка и настройка плагина

### 1. Установка плагина в Cardinal
Никаких файлов вручную в папки закидывать **не нужно**! Установка происходит в пару кликов прямо через Telegram:
1. Откройте диалог с вашим Telegram-ботом управления **FunPay Cardinal**.
2. Откройте главное меню: нажмите **Меню** (или отправьте `/menu`).
3. Перейдите в раздел **🧩 Плагины** ➡️ **➕ Добавить плагин**.
4. Отправьте файл `auto_smm_v2.py` в чат боту.
5. Готово! Плагин успешно установлен и активирован.

---

### 2. Подключение API
После установки отправьте боту команду:
```text
/autosmm
```
В открывшейся панели управления:
1. Нажмите кнопку **`🔗 API URL`** и отправьте ссылку на API сервиса:
   ```text
   https://soc-rocket.ru/api/v2/
   ```
2. Нажмите кнопку **`🔑 API Token`** и отправьте ваш API-токен из настроек сайта. Бот зашифрует его под спойлер и сразу протестирует связь с сервисом, показав баланс.
3. В кнопке **`⚙️ Настройки и уведомления`** вы можете включить/выключить:
   - Уведомления о новых заказах и ошибках.
   - Автовозврат средств покупателю на FunPay в случае ошибки SMM.
   - Разрешение закрытых каналов Telegram.
   - Авто-пересоздание остатка при частичном выполнении (Partial).

## 🏷️ Настройка лотов на FunPay

Лоты можно создавать в любой категории FunPay.

Чтобы бот понял, что купленный лот — это автонакрутка, **вставьте в описание лота (или скрытое описание)** параметры:

```text
ID: <номер_услуги>
```
*(номер услуги берётся из прайс-листа сервиса, он указан рядом с названием услуги).*

### 🔢 Множитель количества (`#Quan:`)
Если вы продаёте услугу пакетами (например, лот на 500 или 1000 штук), используйте параметр:
```text
#Quan: <число>
```
Множитель умножает количество купленных лотов на указанное число.

---

### 📋 Примеры настройки описания:

* **Пример 1 (поштучная продажа):**
  Покупатель сам выбирает количество (например, покупает 300 подписчиков).
  > В описании лота пишем:
  > ```text
  > Быстрые качественные подписчики на канал.
  > ID: 14
  > ```
  *Итог: запустится ровно 300 шт.*

* **Пример 2 (продажа готовым пакетом):**
  Лот называется «Пакет 1000 просмотров на пост». Покупатель покупает 1 лот.
  > В описании лота пишем:
  > ```text
  > 1000 просмотров на любой пост без списаний.
  > ID: 82 #Quan: 1000
  > ```
  *Итог: при покупке 1 лота накрутится `1 * 1000 = 1000 шт.`. Если покупатель купит 3 таких лота, накрутится `3 * 1000 = 3000 шт.`*

## 💬 Команды для покупателей в чате FunPay

Покупатель прямо в чате заказа FunPay может использовать команды:
* `#статус <ID_SMM>` — узнать текущий статус заказа, стартовое число и сколько осталось накрутить.
* `#рефилл <ID_SMM>` — запросить автоматическую докрутку по гарантии (если услуга её поддерживает).
